# clearanceai Flow

This project defines a declarative CrewAI Flow in `src/clearanceai/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/clearanceai/flow.yaml` to change the flow. Add reusable crews under `src/clearanceai/crews/`, custom Python tools under `src/clearanceai/tools/`, and shared knowledge files under `src/clearanceai/knowledge/`.
